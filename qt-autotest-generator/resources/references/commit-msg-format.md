# 提交信息格式规范

> 本技能 `code_committer`（生成）与 `self_checker` 提交规范自检模式（校验）的**单一权威文档**。两者均以本文档的模板与正则为准，避免生成与校验不同步。
>
> `code_committer` 第 5/6 步生成与提交前自校验、`self_checker(commit_check=true)` 第 4 步提交后规范自检，均引用本文档，不再各自维护一份正则。

## 1. 完整模板

```
test: add autotests for <project> batch <N> (<cumulative_classes>/<cumulative_total> classes)

Generated by qt-autotest-generator skill.
Batch <N>: <batch_classes_str>
Cumulative: <cumulative_classes>/<cumulative_total> classes, <cumulative_tested>/<cumulative_methods> methods tested
Baseline: <branch> @ <short-sha> "<commit-title>" (<date>)

Log: 新增 <project> 单元测试
Influence: 新增 <batch_done_count> 个类的单元测试，本批次覆盖率 <batch_tested>/<batch_methods>，累计覆盖率 <cumulative_tested>/<cumulative_methods>
```

### 字段含义

| 字段 | 来源 |
|------|------|
| `<project>` | `session.project_path` 末段 |
| `<N>` | 本批次序号（从 `session.commit_history` 长度 +1 推导） |
| `<cumulative_classes>` / `<cumulative_total>` | 累计 `status=done` 类数 / 总类数 |
| `<cumulative_tested>` / `<cumulative_methods>` | 累计已测方法数 / 累计方法总数 |
| `<batch_classes_str>` | 本批次新完成类清单，逗号分隔 |
| `<batch_done_count>` | 本批次新完成类数 |
| `<batch_tested>` / `<batch_methods>` | 本批次方法覆盖（已测 / 总数） |
| `<branch>` / `<short-sha>` / `<commit-title>` / `<date>` | 基线 commit 信息，取自 `session.branch` / `baseline_commit` / `baseline_title` / `baseline_date` |

## 2. 字段正则校验

`self_checker(commit_check=true)` 用以下正则逐行校验 `git log -1 --format=%B <sha>` 输出：

| 字段 | 正则 | 失败码 |
|------|------|--------|
| 标题行 | `^test: add autotests for .+ batch [0-9]+ \([0-9]+/[0-9]+ classes\)$` | `FAIL_TITLE` |
| 基线 commit | `^Baseline: .+ @ .+ \".+\" \(.+\)$` | `FAIL_BASELINE` |
| 本批次类列表 | `^Batch [0-9]+: .+$` | `FAIL_BATCH_LINE` |
| 累计统计 | `^Cumulative: [0-9]+/[0-9]+ classes, [0-9]+/[0-9]+ methods tested$` | `FAIL_CUMULATIVE` |
| Log 行 | `^Log: .+$` | `FAIL_LOG` |
| Influence 行 | `^Influence: .+[0-9]+/[0-9]+.+$` | `FAIL_INFLUENCE` |

任一 `FAIL_*` → 提交规范自检不通过 → 回到代码提交阶段 amend 本批次**未 push** commit 仅修正 message（已 push 的 commit 禁止 amend；文件层面误提交必须新 commit 撤销，不 amend）。

## 3. 校验脚本

`self_checker(commit_check=true)` 第 4 步直接执行：

```bash
SHA="$1"
MSG_FILE=$(mktemp)
git log -1 --format=%B "$SHA" > "$MSG_FILE"

grep -E '^test: add autotests for .+ batch [0-9]+ \([0-9]+/[0-9]+ classes\)$' "$MSG_FILE" || echo "FAIL_TITLE"
grep -E '^Baseline: .+ @ .+ \".+\" \(.+\)$' "$MSG_FILE" || echo "FAIL_BASELINE"
grep -E '^Batch [0-9]+: .+$' "$MSG_FILE" || echo "FAIL_BATCH_LINE"
grep -E '^Cumulative: [0-9]+/[0-9]+ classes, [0-9]+/[0-9]+ methods tested$' "$MSG_FILE" || echo "FAIL_CUMULATIVE"
grep -E '^Log: .+$' "$MSG_FILE" || echo "FAIL_LOG"
grep -E '^Influence: .+[0-9]+/[0-9]+.+$' "$MSG_FILE" || echo "FAIL_INFLUENCE"

rm -f "$MSG_FILE"
```
